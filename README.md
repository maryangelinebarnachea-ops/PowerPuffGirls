## App name:
NUluminate (Not Under Limits – Uplifting Minds, Motivating ideas, Nurturing Action Towards Empowerment)

______________________________________

## Description:
The web application is a Student Wellness Check-In System designed to allow students to regularly submit their wellness status in a simple and non-medical way. It helps monitor general student well-being through mood and stress check-ins and provides summarized insights for faculty or guidance staff. The system promotes awareness of student wellness and helps identify possible concerns early through basic reporting tools.

______________________________________

## Target audience:
• Students

• Faculty

• Staff from National University

______________________________________

## Goal:
To develop a simple and secure wellness monitoring system for students where:

• Students can submit daily or weekly wellness check-ins 

• Faculty or staff can view overall wellness trends 

• The system can help identify students who may need support 

• Data is presented in a simple and organized dashboard 

______________________________________

## Problem being solved:
Students often experience stress, burnout, and workload pressure, but there is no simple system in place to monitor general well-being.

This system solves that by:

• Providing a quick way for students to check in 

• Giving staff an overview of student wellness trends 

• Helping the school identify possible concerns early 

• Encouraging self-awareness among students 

______________________________________

## Competition:
(Similar Apps / Systems: Google Forms, School counseling logs) 

Our app is unique because it is designed specifically for NU students, features a simple non-clinical check-in system, supports both anonymous and logged-in submissions, includes a school-based wellness dashboard, provides trend visualization for faculty/admin, and is lightweight and easy to use.

## Use Cases:

## Q1: Do you need registration?*

*A1:* ✔ Yes
Only NU students and staff can register. Requires NU school email (e.g. @nu-laguna.edu) to ensure only trusted users can access the system.

## Q2: Do you save user data?*

*A2:* ✔ Yes
We store necessary data for monitoring and support purposes:
• Student information (name, email, password) 
• Wellness check-in responses 
• Check-in history 
• Admin dashboard analytics 

## Main Features:

## Student Features:


• Register/Login using NU credentials 

• Submit wellness check-in (daily/weekly) 

• Select mood (happy, okay, stressed, exhausted) 

• Rate stress level (1–5 scale) 

• View personal check-in history 

• Optional anonymous submission 


## Faculty / Admin Features:


• View student wellness dashboard 

• See overall class wellness trends 

• Monitor stress levels and mood distribution 

• View check-in history per section 

• Identify students with repeated high stress 

• Manage user accounts
